# 가족 미술관 (kids-gallery) — 3차 (1~4실 테마 · 층 관리)

아이들의 작품 사진을 모아 두고, 가족이 캐릭터로 미술관을 걸어 다니며 보는 웹앱·PWA입니다.
**한 방에 26점**을 걸 수 있는 넓은 전시실과, 캐릭터 조종이 어려운 **어른을 위한 `📖 큰 사진 앨범`** 화면이 있습니다.
`index.html` 한 파일로 동작하고, 구글 시트·드라이브를 연결하면 원본 사진과 목록이 자동으로 쌓입니다.

- 앱 버전: **2.1.0**
- 앱 코드: `index.html` (외부 라이브러리 없음)
- 백엔드: `apps-script/Code.gs` (구글 시트 + 드라이브, v1.0.0 — **그대로 다시 써도 됩니다**)
- 검증: `test/verify.py` → `verification/2026-11-27-v21/`
- 배포: <https://wjoehasa-eng.github.io/kids-gallery/> (GitHub Pages · `main`)

> **2.1.0에서 바뀐 것**
> 1~4실이 계절 테마로 달라졌습니다(벽·바닥 색, 가벽 배치, 소품). 층은 **2026년 = 1층**을 기준으로 고정해
> 2025년은 **B1층**, 2024년은 B2층이 되고, `＋ 연도`의 **층 관리** 창에서 다음/이전 연도나 직접 넣은 연도를 열고
> **빈 층은 지울 수 있습니다**. 작품이 걸린 층과 2026년(기본 층)은 지워지지 않습니다.
>
> 2차에서 바뀐 것: 한 방 10칸 → **26칸**(벽 두 줄 18 + 가벽 8), 방이 커지고 액자 클릭 영역이 넓어졌습니다.
> 26점을 넘으면 같은 방 안에서 **`1관`·`2관`** 으로 나눠 봅니다. 위쪽 **`🏛️ 미술관 산책` / `📖 큰 사진 앨범`** 탭으로 화면을 바꿉니다.
> 데이터 구조(시트 열·드라이브 폴더·백업 JSON)는 1차와 같아서 **기존 기록을 그대로 이어 씁니다.**

## 1. 지금 열어 보는 법

| 방법 | 주소 | 설명 |
|---|---|---|
| 그냥 열기 | `index.html` 더블클릭 | 기기에만 저장되는 모드. 시트 연결은 안 됨 |
| 로컬 서버 | `python3 -m http.server` 후 `http://localhost:8000/` | PWA 설치·서비스워커까지 확인 |
| 예시 작품 | `index.html?demo=1` | 무해한 예시 그림 14점으로 미술관을 채워 봄 (저장되지 않음) |
| 예시 많이 | `index.html?demo=1&fill=26` · `&fill=28` | 한 방에 26점(1관 가득) / 28점(1관 14 + 2관 14)을 걸어 봄 — 칸 수·관 나누기 확인용 |
| 편집 링크 | `index.html#s=<base64 웹앱 주소>` | 열자마자 시트에서 자동으로 불러옴 |
| 관람 링크 | `index.html#v=<base64 웹앱 주소>` | 보기 전용. 올리기·수정·삭제 잠금 |

> `?demo=1` 은 시험용입니다. 실제 작품을 올리면 예시 작품은 사라지고 실제 기록만 저장됩니다.

## 2. 화면 두 가지

위쪽 가운데의 큰 탭으로 바꿉니다. 어느 쪽이든 **관람용 링크(`#v=`)로 들어온 할머니·할아버지도 그대로 쓸 수 있게** 만들었습니다.

### 🏛️ 미술관 산책 (기본)

- **층(엘리베이터)** — **2026년이 기본 1층**입니다. 2027년 = 2층, 2028년 = 3층 … 2025년 = **B1층**, 2024년 = B2층 …
  `＋ 연도` 를 누르면 **층 관리** 창이 열려 `－ 이전 연도` · `＋ 다음 연도` · `원하는 연도 직접 넣기(2000~2100)` 로 층을 엽니다.
  층마다 **빈 층이면 지우기**가 되고, **작품이 1점이라도 걸린 층**과 **2026년(기본 층)** 은 지워지지 않습니다
  (작품이 있으면 `이 층에 작품 N점이 있어 지울 수 없어요` 안내). 보고 있던 층을 지우면 1층(2026년)으로 돌아옵니다.
  좁은 화면에서는 오른쪽 위 가로 칩으로 바뀌고, 층이 많아도 지금 보는 층이 가려지지 않게 자동으로 맞춰집니다.
- **전시실(방)** — 각 층에 `1실(1~3월)`, `2실(4~6월)`, `3실(7~9월)`, `4실(10~12월)`, 방마다 다른 계절 테마.
  작품의 **전시 날짜**에 따라 층과 방이 자동으로 정해집니다. (2025년 작품을 올리면 B1층이 열리고 그 방으로 이동합니다.)
- **한 방에 26칸** — 벽 A·B에 각각 두 줄(5+5, 4+4), 가벽에 8칸. 넓은 12m × 10m 전시실입니다.
  작품이 적으면 벽·가벽에 고르게 펼쳐서 걸립니다.
- **1관 / 2관** — 한 방에 26점을 넘으면 방을 새로 만들지 않고, 같은 방 안에서 `1관`·`2관` 칩으로 나눠 봅니다.
  관마다 고르게 나눕니다(예: 27점 → 1관 14 + 2관 13, 28점 → 14 + 14). 칩은 27점부터 나타나고,
  앨범에서는 관과 상관없이 이 방의 작품을 전부 봅니다.

### 🎨 1~4실 테마

| 전시실 | 테마 | 색감 | 가벽(파티션) 배치 | 소품 |
|---|---|---|---|---|
| 1실 · 1~3월 | 봄 햇살관 | 크림 · 세이지그린 | 중앙 트윈 아일랜드 (나란한 두 가벽) | 우드 벤치 · 화분 · 창가 햇살 |
| 2실 · 4~6월 | 푸른 정원관 | 미스트블루 · 오크 | ㄱ자로 엇갈린 가벽 | 플랜트 박스 · 조각대 · 화분 |
| 3실 · 7~9월 | 노을 아틀리에 | 테라코타 · 샌드 | ㄷ자 회랑형 가벽 | 이젤 · 스탠드 조명 · 라운지 스툴 |
| 4실 · 10~12월 | 겨울 별빛관 | 미드나잇 네이비 · 골드 | 대칭 살롱형 가벽 | 대형 벤치 · 금빛 구 조명 · 별빛 |

- 가벽 모양이 달라도 **벽 18칸 + 가벽 8칸 = 한 방 26칸**은 그대로입니다.
- 캐릭터는 가벽·소품을 뚫고 지나가지 않고 **돌아서 걷습니다**. 방을 바꿔 서 있던 자리가 막히면 안전한 자리로 옮겨 집니다.
- 액자 클릭 영역은 4개 방 모두 화면에서 **7px 더 넓게** 잡혀 있습니다.
- **작가 필터** — `전체 / 아이 1 / 아이 2`.
- **관람 캐릭터** — `아빠 / 엄마 / 아이 1 / 아이 2` 중 선택. 이름은 설정에서 바꿉니다.
- **이동** — 바닥을 누르면 그 자리로 걸어갑니다. 오른쪽 아래 D-pad 를 누르고 있으면 계속 걷습니다
  (`✥` 를 누르면 접고 펼 수 있습니다). PC 에서는 방향키도 됩니다.
- **작품 크게 보기** — 액자를 누르면 열립니다. 액자 클릭 영역은 화면에서 **7px 더 넓게** 잡았습니다.
  창 안에 `‹ ›` 화살표(52px)와 아래 `‹ 이전` / `다음 ›` 큰 버튼(높이 52px), `3 / 26` 위치 표시가 있습니다.
- **안내 문구** — 화면 아래에 `그림을 누르면 크게 보여요 · 어른들은 위 「큰 사진 앨범」을 눌러 보세요`.

### 📖 큰 사진 앨범 (어른용)

- 캐릭터·이동 없이, 작품 원본 사진이 **큼직한 카드**로 이어집니다.
- 카드마다 **제목(19px 굵게) · 작가 · 전시 날짜 · 전시실 · 한 줄 메모**가 큰 글씨로 바로 읽힙니다.
- 위쪽 `이 방 / 전체 작품` 으로 보는 범위를 바꿉니다(전체는 최근 날짜부터).
- 카드를 누르면 **화면 가득 크게 보기**로 이어지고, 그 안에서 `‹ 이전` / `다음 ›` 로 넘깁니다.
  (좁은 화면에서는 작품 보기가 화면을 꽉 채웁니다.)
- 방 탭·작가 필터는 앨범에서도 그대로 쓸 수 있습니다.

## 3. 작품 올리기

`＋ 작품 올리기` → 사진 선택(핸드폰은 촬영 가능) → 전시 날짜(기본 오늘) → 작가 → 제목 → 한 줄 메모 → 저장.

- 사진은 브라우저에서 **긴 변 1600px JPEG** 로 줄여 전송합니다(원본이 12MB 를 넘지 않도록).
- 시트가 연결돼 있으면 원본이 드라이브 폴더에 저장되고, 그 파일 정보가 시트에 기록됩니다.
- 연결 전에 올린 작품의 원본은 **기기(IndexedDB)에 보관**해 두었다가, 시트를 연결하면 자동으로 드라이브에 올립니다.
- 작품을 목록에서 지워도 **드라이브의 원본 사진은 지우지 않습니다**(안전).

## 4. 구글 시트·드라이브 연결 (한 번만, 약 5분)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (예: 「가족미술관 데이터」)
2. 그 시트에서 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 내용을 지우고 `apps-script/Code.gs` 전체를 붙여 넣고 저장합니다.
4. **배포 → 새 배포 → 유형 = 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자** (폰 브라우저에서 열리려면 필요)
   - 배포 → 권한 허용 → `…/exec` 주소 복사
5. 앱의 `⚙ 설정` → **웹 앱 주소**에 붙여 넣고 `연결하고 불러오기`.

> 1차에서 이미 연결해 두었다면 **다시 배포할 필요 없습니다.** `index.html` 만 새로 올리면 됩니다.
> 연결이 안 되면: ① 배포의 액세스 권한이 `모든 사용자`인지, ② 코드를 고친 뒤 **새 버전으로 다시 배포**했는지 확인하세요.
> ③ `시트를 찾을 수 없습니다` 오류가 나면 `Code.gs` 맨 위 `SHEET_ID` 에 시트 주소의 `/d/<ID>/` 부분을 넣고 다시 배포하세요.

연결되면 주소창이 `…/index.html#s=<base64>` 로 바뀝니다. 그 주소를 즐겨찾기나 홈 화면에 두면 다음부터 바로 연결됩니다.

### 만들어진 것

```
가족미술관_작품원본/            ← 드라이브 폴더 (스크립트가 자동 생성)
  2026/
    1실_1~3월/  2026-02-11_아이1_무지개마을.jpg
    2실_4~6월/  …
```

| 시트 탭 | 열 |
|---|---|
| `작품목록` | id, date, year, room, artist, title, memo, driveFileId, driveUrl, thumbUrl, createdAt, updatedAt |
| `설정` | 항목, 값 — museumTitle, artist1, artist2, dadName, momName, kid1Name, kid2Name |

- `artist` 는 `a1` / `a2`, `room` 은 1~4, `year` 는 전시 날짜의 연도입니다.
- 시트와 드라이브 폴더만 있으면 다른 앱이나 PC에서 원본 사진과 목록을 그대로 뽑아 쓸 수 있습니다.
- `1관/2관` 은 화면에서 나누는 것뿐이라 시트에는 아무 것도 더 생기지 않습니다.

## 5. 링크 두 가지

`링크` 버튼에서 복사합니다. 두 링크 모두 `#` 뒤에 웹앱 주소를 base64 로 담고 있습니다.

- **관람용 `#v=`** — 가족에게 보내는 링크. 올리기·수정·삭제·층 관리(연도 추가/삭제)가 잠기고 `관람 전용` 표시가 뜹니다.
- **편집용 `#s=`** — 내 기기·공용 PC용. 연결 즉시 시트에서 자동으로 불러오고, 바뀐 내용을 자동 저장합니다.

> 링크를 아는 사람은 그 미술관을 볼 수 있습니다(편집 링크는 고칠 수도 있습니다). 가족 밖으로 나가지 않게 보관하세요.

## 6. 개인정보 원칙

- 코드·데모·검증 스크립트에는 **가족 실명, 학교·어린이집 이름, 전화번호, 이메일, 실제 시트 ID, 실제 `/exec` 주소가 없습니다.**
  기본 표시 이름은 `아이 1` · `아이 2` · `아빠` · `엄마` 뿐입니다.
- 실제 이름은 연결된 **비공개 시트의 `설정` 탭**에서만 옵니다(앱이 불러와 화면에만 표시).
- 드라이브 파일 이름도 `2026-02-11_아이1_제목.jpg` 처럼 **역할 이름**만 씁니다.
- `Code.gs` 의 `SHARE_ARTWORK` (기본 `true`) 는 원본 사진을 "링크가 있는 사람 보기"로 풀어 줍니다.
  가족이 관람 링크로 사진을 보려면 필요합니다. 원본을 완전히 비공개로 두려면 `false` 로 바꾸세요.
  (그때는 앱이 기기에 들고 있는 미리보기 사진으로 보여 줍니다. 큰 사진 앨범도 미리보기로 보입니다.)

## 7. 백업

- `설정 → JSON 내보내기` : 목록·설정 전체(연도·전시실 포함)를 파일로 저장.
- `설정 → CSV 내보내기` : 스프레드시트에서 바로 열 수 있는 목록.
- `설정 → JSON 가져오기` : 다른 기기에서 만든 백업을 합칩니다(같은 id 는 최신 것 유지).
- 시트가 연결돼 있으면 앱이 바뀐 내용을 자동으로 저장하고, 열 때 자동으로 불러와 **기기 자료와 시트 자료를 합칩니다.**
- 빈 목록으로 시트를 지우지 않도록 `Code.gs` 가 막습니다(정말 지울 때만 `clear:true`).

## 8. 검증

```bash
python3 work/kids-gallery/test/verify.py
```

- 결과: `verification/2026-11-27-v21/result.json` (**222개 점검 전부 통과**)
- 화면: 같은 폴더의 `01-gallery-main.png` … `25-mobile-floors.png`
- 확인 항목(1차 + 2차 + 2.1):
  - **층 규칙·층 관리** — 2026년=1층 / 2027년=2층 / 2025년=B1층 / 2024년=B2층,
    `＋ 연도` 팝업에서 이전·다음 연도와 직접 입력으로 층 열기, **빈 층만 삭제**, 작품이 있는 층은 삭제 차단,
    2026년은 기본 층으로 삭제 불가, 층을 더하고 지워도 **2026년(1층)이 그대로**인지,
    작품 0점·데모를 꺼도 2026년 유지, 2025년 작품을 올리면 B1층이 열리고 그 방으로 이동
  - **1~4실 테마** — 네 방의 이름·색감·가벽 배치·소품이 모두 다르고 **4실 모두 26칸**인지,
    방마다 26점을 걸고 **액자 26개를 하나씩 눌러 그 작품이 열리는지**, 가벽을 돌아 걷고 벽·소품에 끼지 않는지,
    방을 바꿔도 캐릭터가 갇히지 않는지
  - **층 칩(모바일 390×844)** — 층이 5개여도 가로 넘침 0건, 지금 보는 층 칩과 2026년 칩이 잘리지 않고 보이는지
